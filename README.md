# StudyPath

해외 유학을 준비하는 사용자가 필요한 준비 과정을 한눈에 확인하고 관리할 수 있도록 만든 서비스입니다.

## 구현하면서 바꾼 구조와 변경 이유

- 처음 예제에서는 마지막 영역이 `소식 받기`였는데, 저는 서비스의 핵심 기능이 더 잘 보이도록 `시작하기` 영역으로 바꿨습니다.
  사용자가 서비스 내용을 본 뒤 바로 유학 준비를 시작할 수 있게 하고 싶었습니다.

- `시작하기` 영역에는 목표 국가를 입력하는 form을 추가했습니다.
  단순히 내용을 읽는 페이지보다 사용자가 직접 입력하고 다음 행동으로 이어지는 구조가 더 자연스럽다고 생각했습니다.

- 목표 국가 입력과 이메일 소식 받기는 하나의 기능처럼 보이지 않도록 form을 나눴습니다.
  목표 국가 입력은 서비스 이용을 위한 핵심 행동이고, 이메일 입력은 유학 관련 소식을 받기 위한 부가 기능이기 때문입니다.

- 입력창에는 `placeholder`를 추가했습니다.
  사용자가 어떤 형식으로 입력하면 되는지 바로 알 수 있도록 예시를 넣었습니다.

- 서비스 소개에 있던 긴 설명은 제목보다는 본문에 가깝다고 생각해서 `h` 태그 대신 `p` 태그를 사용했습니다.
  제목과 설명의 역할을 나누기 위해 수정했습니다.


## 직접 구현한 HTML과 AI 생성 HTML 비교

### 정보 계층

직접 구현할 때는 필요한 내용을 먼저 넣는 데 집중해서 제목과 설명의 역할이 조금 섞여 있었습니다.

AI가 만든 HTML과 비교해 보니 제목은 제목답게 짧게 쓰고,
설명은 `p` 태그로 구분하는 것이 더 자연스럽다고 느껴 수정했습니다.


### 시맨틱 구조

페이지는 `header`, `nav`, `main`, `section`, `footer`로 나눴습니다.

AI 코드와 비교하면서 단순히 태그를 사용하는 것보다
각 영역이 어떤 역할을 하는지 구분하는 것이 중요하다는 점을 알게 되었습니다.

또한 목표 국가 입력과 이메일 소식 받기를 각각 별도의 `form`으로 나눠
두 기능의 목적이 다르다는 점이 보이도록 했습니다.


### 접근성

이미지에는 내용을 설명하는 `alt`를 작성했고,
입력창에는 각각 `label`을 연결했습니다.

또한 `label`의 `for` 값과 `input`의 `id` 값을 같게 맞추고,
`placeholder`에 입력 예시를 넣어 사용자가 입력 방법을 더 쉽게 이해할 수 있도록 했습니다.
