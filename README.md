# StudyPath

StudyPath는 해외 유학을 준비하는 사용자가 목표 국가를 정하고, 현재 준비 상태를 확인하며 유학 준비 과정을 단계적으로 관리할 수 있도록 만든 서비스입니다.

## 현재 프로젝트 설명

### 주요 사용자

해외 유학을 준비하는 학생과 직장인을 주요 사용자로 설정했습니다.

### 서비스 목적

학교 조사, 어학 시험, 지원 서류 등 여러 단계로 나뉘는 유학 준비 과정을 한눈에 확인하고 자신의 현재 준비 상태를 관리할 수 있도록 하는 것이 목적입니다.

### 핵심 행동

사용자가 `유학 준비 시작하기` 버튼을 누른 뒤 목표 국가를 입력하고, 현재까지 완료한 준비 항목을 선택해 자신의 유학 준비 플랜을 완성합니다.

### 완료 조건

목표 국가와 준비 상태를 확인한 뒤 `플랜 완성하기` 버튼을 눌러 `유학 준비 플랜이 완성되었습니다` 화면에 도달하면 핵심 행동이 완료됩니다.

## 사용자 흐름

1. `유학 준비 시작하기` 버튼을 눌러 준비 플랜 작성을 시작합니다.
2. 목표 국가를 입력합니다.
3. 현재까지 완료한 유학 준비 항목을 선택합니다.
4. 목표 국가, 준비 진행률, 완료한 항목을 확인합니다.
5. `플랜 완성하기`를 눌러 유학 준비 플랜을 완료합니다.

목표 국가를 입력하지 않은 경우에는 다음 단계로 넘어가지 않고 입력 방법을 안내합니다.

현재까지 완료한 준비 항목이 없는 경우에는 체크하지 않고 다음 단계로 진행할 수 있습니다.

이전 단계로 돌아가도 입력한 목표 국가와 선택한 준비 항목은 유지됩니다. 내용을 수정한 뒤 다시 확인하면 변경된 값이 확인 화면에 반영됩니다.

플랜 완료 후 `다시 시작하기`를 누르면 입력값, 체크 상태, 오류 문구, 진행률이 초기화되고 첫 단계부터 다시 시작할 수 있습니다.

## 주요 기능

### 주요 기능 탭

`맞춤 준비 일정`, `어학 시험 관리`, `지원 서류` 세 개의 탭을 구현했습니다.

탭을 클릭하면 선택된 탭의 스타일이 변경되고 해당 탭과 연결된 내용만 화면에 표시됩니다.

### 나만의 유학 준비 플랜

목표 국가를 입력하고 현재까지 완료한 준비 항목을 선택할 수 있습니다.

체크 상태에 따라 준비 진행률이 `0 / 3`부터 `3 / 3`까지 변경되며, 진행 중과 완료 상태를 서로 다른 스타일로 표시합니다.

### 입력 오류 안내

목표 국가를 입력하지 않고 다음 단계로 이동하려고 하면 다음 화면으로 넘어가지 않습니다.

오류 문구와 오류 스타일을 표시하고 입력창에 포커스를 이동해 수정해야 할 내용을 알 수 있도록 했습니다.

### 이전 및 수정

이전 단계로 이동해도 입력한 목표 국가와 체크한 준비 항목이 유지됩니다.

내용을 수정하고 다시 확인 단계로 이동하면 수정된 값이 확인 화면에 반영됩니다.

### 완료 및 다시 시작

`플랜 완성하기` 버튼을 누르면 완료 화면이 표시됩니다.

`다시 시작하기` 버튼을 누르면 목표 국가, 준비 항목, 오류 상태, 준비 진행률이 모두 초기화됩니다.

### 유학 소식 받기

이메일을 입력하면 유학 소식 신청이 가능하며 신청 완료 시 안내 문구와 버튼 상태가 변경됩니다.

유학 준비 과정에서 입력한 목표 국가와 현재 준비 진행률도 신청 결과에 반영되도록 연결했습니다.

신청 완료 후 이메일을 수정하면 `소식 받기` 버튼이 다시 활성화됩니다.

## 3주차 CSS 수정 기록

### 수정 이유

설명과 이미지를 가로로 배치해 서비스 소개 내용을 한눈에 보기 쉽도록 수정했습니다.

## 5주차 JavaScript 수정 기록

### 추가한 기능

이메일을 입력하고 `소식 받기` 버튼을 누르면 신청 완료 안내 문구가 표시되도록 기능을 추가했습니다.

### 구현한 내용

JavaScript에서 입력값을 확인하고 조건문과 함수를 사용해 신청 결과에 따라 안내 문구를 변경했습니다.

신청이 완료되면 성공 스타일을 적용하고 버튼 문구를 `신청 완료`로 바꾼 뒤 비활성화했습니다.

### 확인한 결과

PC와 모바일 화면에서 이메일 입력과 신청 기능이 정상적으로 작동하고 안내 문구와 버튼 상태가 변경되는 것을 확인했습니다.

## 6주차 JavaScript 이벤트와 동적 UI 수정 기록

### 구현한 이벤트

주요 기능 영역에 세 개의 탭을 만들고 각 탭에 `click` 이벤트를 적용했습니다.

목표 국가 입력창에는 `input` 이벤트를 적용해 국가를 입력하면 유학 준비 체크리스트 제목이 바로 변경되도록 했습니다.

유학 준비 체크리스트에는 `change` 이벤트를 적용해 선택한 항목 수에 따라 준비 진행률이 변경되도록 했습니다.

### 화면 변화

체크리스트를 선택하면 준비 진행률 문구가 `0 / 3`에서 `1 / 3`, `2 / 3`, `3 / 3`으로 변경됩니다.

진행 중일 때와 모든 항목을 완료했을 때 진행률 안내 영역의 스타일도 다르게 표시되도록 했습니다.

주요 기능의 탭을 선택하면 선택된 탭의 스타일이 변경되고 해당 탭과 연결된 내용만 화면에 표시되도록 구현했습니다.

기존 뉴스레터 신청 기능에는 위에서 입력한 목표 국가와 준비 진행률이 신청 결과에 반영되도록 연결했습니다.

또한 신청 완료 후 이메일을 수정하면 버튼이 다시 `소식 받기` 상태로 활성화되도록 수정했습니다.

### 테스트 결과

1100px, 768px, 390px 화면에서 탭 클릭, 목표 국가 입력, 체크리스트 선택, 뉴스레터 신청 기능을 확인했습니다.

각 화면에서 내용이 잘리거나 가로 스크롤이 생기지 않았으며 선택한 탭의 내용만 표시되고 입력값과 체크 상태에 따른 화면 변화가 정상적으로 작동하는 것을 확인했습니다.

## 중간고사 추가 기능

### 새로 추가한 기능

7주차에 구현한 유학 준비 플랜 완료 화면에 `목표 입학일까지 남은 준비 기간 확인` 기능을 추가했습니다.

사용자가 목표 입학일을 선택하면 현재 날짜와 비교해 입학일까지 남은 일수를 계산하고 화면에 표시하도록 구현했습니다.

### 사용자 행동과 조건

사용자는 유학 준비 플랜을 완성한 뒤 목표 입학일을 선택하고 `남은 준비 기간 확인하기` 버튼을 누릅니다.

목표 입학일을 입력하지 않은 경우에는 계산을 진행하지 않고 `목표 입학일을 선택해 주세요.`라는 안내를 표시합니다.

오늘 또는 과거 날짜를 선택한 경우에는 `오늘 이후의 입학 목표일을 선택해 주세요.`라는 안내를 표시해 날짜를 다시 선택할 수 있도록 했습니다.

정상적인 미래 날짜를 선택하면 현재 날짜와 목표 입학일 사이의 남은 일수를 계산합니다.

### 성공 반응

정상적인 미래 날짜를 선택하면 기존 유학 준비 흐름에서 입력한 목표 국가와 함께 입학일까지 남은 일수를 화면에 표시합니다.

예를 들어 목표 국가가 독일인 경우 `독일 유학 목표일까지 700일 남았습니다.`와 같이 결과가 표시됩니다.

### 오류 반응

목표 입학일이 비어 있거나 오늘 또는 과거 날짜인 경우에는 결과를 표시하지 않고 사용자가 수정해야 할 내용을 안내합니다.

오류가 발생하면 목표 입학일 입력창으로 포커스를 이동해 바로 수정할 수 있도록 했습니다.

### 다시 시작

기존 `다시 시작하기` 버튼을 누르면 목표 국가와 준비 체크리스트뿐 아니라 새로 입력한 목표 입학일, 오류 문구, 계산 결과도 함께 초기화되도록 했습니다.
