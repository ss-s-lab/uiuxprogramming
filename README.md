## 구현하면서 바꾼 구조와 변경 이유

- 기존의 `서비스 소개 → 주요 기능 → 이용 방법 → 소식 받기` 구조를
  `서비스 소개 → 주요 기능 → 이용 방법 → 시작하기` 구조로 변경했다.
  사용자가 서비스 내용을 확인한 뒤 바로 유학 준비를 시작할 수 있도록 하기 위해서다.

- 기존의 `소식 받기` section을 `시작하기` section으로 변경하고,
  목표 국가를 입력하는 form을 추가했다.
  StudyPath의 핵심 행동인 목표 국가 입력과 준비 과정 확인을 페이지의 마지막 행동으로 연결하기 위해서다.

- `시작하기` section 안에 목표 국가 입력 form과 이메일 소식 받기 form을 분리해서 구성했다.
  목표 국가 입력은 서비스의 핵심 행동이고, 이메일 입력은 유학 소식을 받기 위한 부가 행동이기 때문이다.

- 서비스 소개 영역의 긴 설명을 제목 요소가 아닌 문단으로 구성했다.
  서비스 설명은 제목이 아니라 본문 정보에 해당하므로 정보 계층을 더 명확하게 표현하기 위해서다.
