# StudyPath

해외 유학을 준비하는 사용자가 필요한 준비 과정을 한눈에 확인하고 관리할 수 있도록 만든 서비스입니다.

## 구현하면서 바꾼 구조와 변경 이유

- 처음 예제에서는 마지막 영역이 `소식 받기`였는데, 저는 서비스의 핵심 기능이 더 잘 보이도록 `시작하기` 영역으로 바꿨습니다.
  사용자가 서비스 내용을 본 뒤 바로 유학 준비를 시작할 수 있게 하고 싶었습니다.

- `시작하기` 영역에는 목표 국가를 입력하는 form을 추가했습니다.
  단순히 내용을 읽는 페이지보다 사용자가 직접 입력하고 다음 행동으로 이어지는 구조가 더 자연스럽다고 생각했습니다.

- 목표 국가 입력과 이메일 소식 받기는 하나의 기능처럼 보이지 않도록 form을 나눴습니다.
  목표 국가 입력은 서비스 이용을 위한 핵심 행동이고, 이메일 입력은 유학 관련 소식을 받기 위한 부가 기능이기 때문입니다.

- 입력창에는 `placeholder`를 추가했습니다.
  사용자가 어떤 형식으로 입력하면 되는지 바로 알 수 있도록 예시를 넣었습니다.

- 서비스 소개에 있던 긴 설명은 제목보다는 본문에 가깝다고 생각해서 `h` 태그 대신 `p` 태그를 사용했습니다.
  제목과 설명의 역할을 나누기 위해 수정했습니다.


## 직접 구현한 HTML과 AI 생성 HTML 비교

### 정보 계층

직접 구현할 때는 필요한 내용을 먼저 넣는 데 집중해서 제목과 설명의 역할이 조금 섞여 있었습니다.

AI가 만든 HTML과 비교해 보니 제목은 제목답게 짧게 쓰고,
설명은 `p` 태그로 구분하는 것이 더 자연스럽다고 느껴 수정했습니다.


### 시맨틱 구조

페이지는 `header`, `nav`, `main`, `section`, `footer`로 나눴습니다.

AI 코드와 비교하면서 단순히 태그를 사용하는 것보다
각 영역이 어떤 역할을 하는지 구분하는 것이 중요하다는 점을 알게 되었습니다.

또한 목표 국가 입력과 이메일 소식 받기를 각각 별도의 `form`으로 나눠
두 기능의 목적이 다르다는 점이 보이도록 했습니다.


### 접근성

이미지에는 내용을 설명하는 `alt`를 작성했고,
입력창에는 각각 `label`을 연결했습니다.

또한 `label`의 `for` 값과 `input`의 `id` 값을 같게 맞추고,
`placeholder`에 입력 예시를 넣어 사용자가 입력 방법을 더 쉽게 이해할 수 있도록 했습니다.

# StudyPath

StudyPath는 해외 유학을 준비하는 사용자가 목표 국가를 정하고, 현재 준비 상태를 확인하며 유학 준비 과정을 단계적으로 관리할 수 있도록 만든 서비스입니다.

## 현재 프로젝트 설명

### 주요 사용자

해외 유학을 준비하는 학생과 직장인을 주요 사용자로 설정했습니다.

### 서비스 목적

학교 조사, 어학 시험, 지원 서류 등 여러 단계로 나뉘는 유학 준비 과정을 한눈에 확인하고 자신의 현재 준비 상태를 관리할 수 있도록 하는 것이 목적입니다.

### 핵심 행동

사용자가 `유학 준비 시작하기`를 누른 뒤 목표 국가를 입력하고, 현재까지 완료한 준비 항목을 선택해 자신의 유학 준비 플랜을 완성합니다.

### 완료 조건

목표 국가와 준비 상태를 확인한 뒤 `플랜 완성하기` 버튼을 눌러 `유학 준비 플랜이 완성되었습니다` 화면에 도달하면 핵심 행동이 완료됩니다.

## 사용자 흐름

1. `유학 준비 시작하기` 버튼을 눌러 준비 플랜 작성을 시작합니다.
2. 목표 국가를 입력합니다.
3. 현재까지 완료한 유학 준비 항목을 선택합니다.
4. 목표 국가, 준비 진행률, 완료한 항목을 확인합니다.
5. `플랜 완성하기`를 눌러 유학 준비 플랜을 완료합니다.

목표 국가를 입력하지 않은 경우에는 다음 단계로 넘어가지 않고 입력 방법을 안내합니다.

현재까지 완료한 준비 항목이 없는 경우에는 체크하지 않고 다음 단계로 진행할 수 있습니다.

이전 단계로 돌아가도 입력한 국가와 선택한 준비 항목은 유지됩니다. 내용을 수정한 뒤 다시 확인하면 변경된 값이 확인 화면에 반영됩니다.

플랜 완료 후 `다시 시작하기`를 누르면 입력값, 체크 상태, 오류 문구, 진행률이 초기화되고 첫 단계부터 다시 시작할 수 있습니다.

## 주요 기능

### 주요 기능 탭

`맞춤 준비 일정`, `어학 시험 관리`, `지원 서류` 세 개의 탭을 구현했습니다.

탭을 클릭하면 선택된 탭의 스타일이 변경되고, 해당 탭과 연결된 내용만 화면에 표시됩니다.

### 나만의 유학 준비 플랜

목표 국가를 입력하고 현재까지 완료한 준비 항목을 선택할 수 있습니다.

체크 상태에 따라 준비 진행률이 `0 / 3`부터 `3 / 3`까지 변경되며, 진행 중과 완료 상태를 서로 다른 스타일로 표시합니다.

### 입력 오류 안내

목표 국가를 입력하지 않고 다음 단계로 이동하려고 하면 다음 화면으로 넘어가지 않습니다.

오류 문구와 오류 스타일을 표시하고 입력창으로 포커스를 이동해 수정해야 할 내용을 알 수 있도록 했습니다.

### 이전 및 수정

이전 단계로 이동해도 입력한 목표 국가와 체크한 준비 항목이 유지됩니다.

내용을 수정하고 다시 확인 단계로 이동하면 수정된 값이 확인 화면에 반영됩니다.

### 완료 및 다시 시작

`플랜 완성하기`를 누르면 완료 화면이 표시됩니다.

`다시 시작하기`를 누르면 목표 국가, 준비 항목, 오류 상태, 진행률이 모두 초기화됩니다.

### 유학 소식 받기

이메일을 입력하면 유학 소식 신청이 가능하며, 신청 완료 시 안내 문구와 버튼 상태가 변경됩니다.

유학 준비 과정에서 입력한 목표 국가와 현재 준비 진행률도 신청 결과에 반영되도록 연결했습니다.

신청 완료 후 이메일을 수정하면 `소식 받기` 버튼이 다시 활성화됩니다.

# 6주차 JavaScript 이벤트와 동적 UI 수정 기록

## 구현한 이벤트

주요 기능 영역에 세 개의 탭을 만들고
각 탭에 click 이벤트를 적용했습니다.

목표 국가 입력창에는 input 이벤트를 적용해
국가를 입력하면 유학 준비 체크리스트 제목이 바로 변경되도록 했습니다.

유학 준비 체크리스트에는 change 이벤트를 적용해
선택한 항목 수에 따라 준비 진행률이 변경되도록 했습니다.

## 화면 변화

체크리스트를 선택하면 준비 진행률 문구가
`0 / 3`에서 `1 / 3`, `2 / 3`, `3 / 3`으로 변경됩니다.

진행 중일 때와 모든 항목을 완료했을 때
진행률 안내 영역의 스타일도 다르게 표시되도록 했습니다.

주요 기능의 탭을 선택하면 선택된 탭의 스타일이 변경되고
해당 탭과 연결된 내용만 화면에 표시되도록 구현했습니다.

기존 뉴스레터 신청 기능에는
위에서 입력한 목표 국가와 준비 진행률이 신청 결과에 반영되도록 연결했습니다.

또한 신청 완료 후 이메일을 수정하면
버튼이 다시 `소식 받기` 상태로 활성화되도록 수정했습니다.
